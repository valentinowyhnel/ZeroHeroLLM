LLM02: Laboratoire de gestion non sécurisée des sorties

Objectif : Exploiter la gestion non sécurisée de la sortie du LLM pour exécuter du code arbitraire dans le navigateur (XSS).

Le système est conçu pour vous saluer. Entrez votre nom et le LLM générera un message d'accueil. Essayez de voir si vous pouvez faire en sorte que la sortie exécute une alerte JavaScript.

Vulnérabilité exploitée !

Description : Vous avez réussi à exploiter une vulnérabilité de type Cross-Site Scripting (XSS). Le LLM a généré une sortie contenant du code JavaScript, et l'application l'a rendue directement dans le HTML sans la nettoyer. Cela permet à un attaquant d'exécuter du code dans le navigateur des autres utilisateurs, de voler des cookies de session, de défigurer le site web ou de rediriger les utilisateurs vers des sites malveillants.

Comment se protéger :

  • Encodez la sortie : Assurez-vous que toutes les données provenant du LLM sont correctement encodées pour le contexte dans lequel elles sont affichées (HTML, JavaScript, etc.). Par exemple, en utilisant des fonctions comme `htmlspecialchars` en PHP ou l'échappement automatique de Jinja2.
  • Validez la sortie : Dans la mesure du possible, validez la sortie du LLM pour vous assurer qu'elle correspond au format attendu.
  • Appliquez une politique de sécurité du contenu (CSP) : Mettez en place une CSP stricte pour limiter les sources de scripts et autres ressources, réduisant ainsi l'impact des attaques XSS.
