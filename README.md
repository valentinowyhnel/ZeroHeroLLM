**ZeroHeroLLM** is an interactive, educational web application designed to teach the fundamentals of Large Language Model (LLM) security. It provides a safe, hands-on environment where beginners and professionals can explore, exploit, and understand the top 10 security risks associated with LLM applications, as defined by the **OWASP Top 10 for LLM Security** project.

The project features a series of labs, each dedicated to a specific vulnerability, complete with vulnerable LLM implementations, detailed explanations, and clear success/failure criteria.

## 🚀 Features

-   **10 Interactive Labs:** One for each vulnerability in the OWASP Top 10 for LLMs.
-   **Hands-On Exploitation:** A safe environment to run real attacks against vulnerable (simulated and real) LLMs.
-   **Local First:** Powered by **Ollama**, allowing you to run powerful open-source models like Llama 3 on your own machine without any API keys.
-   **Educational Content:** Each lab includes detailed documentation on the risk, attack scenarios, and secure coding practices.
-   **Immediate Feedback:** A clear validation mechanism tells you instantly if your exploit attempt was successful.

## 🛠️ Tech Stack

-   **Backend:** [Flask](https://flask.palletsprojects.com/) (Python)
-   **LLM Backend:** [Ollama](https://ollama.com/)
-   **Frontend:** HTML, CSS, JavaScript (with Jinja2 templating)
-   **Dependencies:** `openai` Python library (used as a generic client for the Ollama API)

## 🎯 The Labs

The labs cover the full range of the OWASP Top 10 for LLM Security:

1.  **LLM01: Prompt Injection:** Bypass system instructions.
2.  **LLM02: Insecure Output Handling:** Trigger frontend vulnerabilities (XSS) from the LLM's output.
3.  **LLM03: Training Data Poisoning:** See how malicious training data can create new vulnerabilities.
4.  **LLM04: Model Denial of Service:** Overwhelm the model with resource-intensive prompts.
5.  **LLM05: Supply Chain Vulnerabilities:** Exploit a backdoored dependency.
6.  **LLM06: Sensitive Information Disclosure:** Trick a RAG system into leaking confidential data.
7.  **LLM07: Insecure Plugin Design:** Abuse an overly permissive LLM tool.
8.  **LLM08: Excessive Agency:** Manipulate an autonomous agent into performing harmful actions.
9.  **LLM09: Overreliance:** Spot insecure code generated by an over-trusted AI assistant.
10. **LLM10: Model Theft:** Understand infrastructure risks that can lead to model exfiltration.

## ⚙️ Installation & Setup

**Prerequisites:**

1.  **Python 3.8+**
2.  **Ollama:** You must have [Ollama installed](https://ollama.com/) and running on your local machine.
3.  **Git**

**Steps:**

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/vulnerabilities/llm-top10-labs.git
    cd llm-top10-labs
    ```

2.  **Download the required LLM model:**
    This project uses `llama3` by default. Pull it via Ollama:
    ```bash
    ollama pull llama3
    ```
    *(Ensure the Ollama application is running in the background).*

3.  **Create and activate a Python virtual environment:**
    ```bash
    python3 -m venv venv
    source venv/bin/activate  # On Windows: venv\Scripts\activate
    ```

4.  **Install Python dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

5.  **Run the application:**
    ```bash
    flask run
    ```

6.  **Open the lab:**
    Navigate to `http://127.0.0.1:5000` in your web browser.
