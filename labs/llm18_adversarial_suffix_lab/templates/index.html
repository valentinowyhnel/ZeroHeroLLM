How it works:

The LLM has a simple filter against the phrase "tell me a secret". However, appending the adversarial suffix changes the prompt in a way that the filter no longer recognizes the forbidden phrase, thus bypassing it.

Mitigation:

Normalizing input (e.g., stripping unusual suffixes), token-level analysis, and computing deltas with and without the suffix can help detect and mitigate these attacks.
