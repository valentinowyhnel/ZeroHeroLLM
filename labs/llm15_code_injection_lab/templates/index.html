How it works:

The simulation checks for a trigger phrase <<TRY_LEAK>>. If found, it returns the placeholder system prompt: SYSTEM_PROMPT_PLACEHOLDER_HONEY. This simulates an attacker trying to extract the underlying system prompt from the LLM.

Important: Never attempt to extract system prompts from real third-party APIs. This lab uses a safe, simulated environment with a placeholder token.
