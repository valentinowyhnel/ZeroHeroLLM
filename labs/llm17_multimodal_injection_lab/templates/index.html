Scenario 7: Multimodal Injection

Goal: To simulate a prompt injection embedded in image metadata that a multimodal model might process.

Multimodal LLM Simulator

This tool simulates a multimodal LLM that "reads" both an image and its metadata. The sample image for this lab has a hidden instruction in its metadata.

How it works:

A sample image is generated with a custom metadata field: X-IMAGE-META:INJECT_HONEY. The simulated LLM reads this metadata and concatenates it with the main prompt, leading to the honeytoken being leaked.

Defenses:

Removing or ignoring image metadata, enforcing OCR sanity checks, and limiting image preprocessing that might reveal hidden layers are common defenses against this type of attack.
